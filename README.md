# OpenTax Japan

日本の法人税申告書（別表）の e-Tax 用データを作るオープンソースです。
特定の税務ソフトに頼らず、国税庁が公開している e-Tax 仕様書（XML構造設計書・帳票フィールド仕様書・XMLスキーマ・帳票間連動仕様書）を一次資料にします。

> **開発中です。** まだ申告には使えません。

## 免責

- **計算結果・出力データの正しさは保証しません。**
- **申告の内容と責任は利用者にあります。** 提出前に必ず利用者自身で確認してください。
- このソフトは国税庁・地方税共同機構と関係がありません。

## 最初の版: OpenTax RED（赤字の単純な法人）

所得金額が0以下の、赤字の単純な法人（普通法人・中小法人・青色申告）を対象にします。

- 法人税: 別表一・別表二（同族会社等の判定）・別表四（簡易様式）・別表五(一)・別表五(二)・別表六(一)（所得税額の控除）・別表七(一)（欠損金）・
  別表十五（交際費等）・別表十六(一)(二)（減価償却。固定資産台帳の数字を写します）
  - 預貯金の利子などの源泉所得税の還付、中間納付の還付、前期の未納法人税等・事業税等の納付も扱います
  - 出力: e-Taxソフト（ダウンロード版）に取り込める `.xtx`。電子署名・送信は e-Taxソフトで行います
- 地方税: 第6号様式（道府県民税・事業税・特別法人事業税）・第6号様式別表九（事業税の欠損金）・第20号様式（市町村民税）・均等割の計算
  - 出力: 計算結果の一覧（欄ごとの金額と PCdesk に入力する順番）。PCdesk への入力・電子署名・送信は利用者が行います
  - 対応している自治体: 岡山県・岡山市・倉敷市・東京都の特別区（自治体ごとの設定ファイルを足せば増やせます）
- 添付書類（.xtx に一緒に入れます）
  - 勘定科目内訳明細書: 預貯金等・売掛金・仮払金/貸付金・買掛金・仮受金/預り金・借入金・役員給与等/人件費・地代家賃・雑益雑損失の9様式。
    会計ソフトの科目残高（TKC の科目残高一覧表 TXT）と給与の記録から作り、足りない欄（相手先の所在地など）は JSON で足します
  - 法人事業概況説明書: 主要科目は科目残高から、従事員・人件費・役員報酬は給与の記録から、そのほかの欄は JSON から作ります（金額は千円未満切捨て）
- 給与の記録: 先方が計算した給与・賞与をそのまま記録し、源泉所得税の納付額・賃金台帳・内訳書の元にします（給与の計算はしません）

### 対象外

次のものは扱いません。**入力に含まれていたら「OpenTax RED の対象外です」というエラーで止まります。**

- 黒字法人の税額計算
- 税額控除（所得税額の控除は預貯金の利子などの源泉所得税だけ扱います。配当など所有期間の按分が要るものは対象外）
- 中間申告そのもの（中間申告で納付した額の控除・還付は扱います）
- 外形標準課税（資本金1億円超）
- 欠損金の繰戻し還付
- グループ通算
- 特別措置の適用（適用額明細書）
- 分割法人（事務所・事業所が2つ以上の都道府県または市町村にある法人）
- 添付書類のうち財務諸表（貸借対照表・損益計算書など）。e-Taxソフトなどで別に添付してください
- eLTAX 用の取込ファイル（地方税共同機構への仕様の開示申込みの回答を待っています）

今後対応予定:
- 黒字法人の税額計算
- 法人税の別表の追加: 受取配当（別表八(一)）・減価償却の計算（減価償却台帳）など
- 会計ソフトの取り込みの追加（エプソン財務など）、月別の売上・仕入の取り込み
- 地方税（eLTAX）の取込ファイル、分割法人
- 消費税（一般課税）・所得税

## 国税庁の仕様書について

仕様書は国税庁の著作物のため、このリポジトリには含めていません。
取得スクリプトが国税庁のサイトからダウンロードし、`.cache/` に置きます。取得したファイルは SHA256 で照合します。

## Web 画面

https://opentax-japan.github.io/opentax-japan/ （独自ドメイン opentax.jp に移る予定）

- ブラウザだけで使えます（Windows ソフトのインストールは不要）
- 計算はブラウザの中で行い、入力した内容はサーバーに送りません。localStorage などにも残しません。保存は「入力をファイルに保存」でダウンロードしたファイルだけです
- e-Tax 用の .xtx を作るときは、国税庁から取った e-tax19.CAB を画面で選びます（その CAB で検証してから書き出します）
- 給与の記録の画面（payroll.html）もあります。内訳書・概況書の画面はこれから作ります（今はコマンドで作れます）

## 使い方

作成済み:
```
opentax fetch-spec --set ksk2-2026-08       # 仕様書の取得と SHA256 照合（--check で国税庁の改訂を検知）
opentax build-layout --set ksk2-2026-08     # XSD から帳票ごとの layout を作る
opentax build-catalog --set ksk2-2026-08    # 帳票フィールド仕様書から field_catalog を作る
opentax build-checks --set ksk2-2026-08     # 帳票の一致チェックを仕様書から作る
opentax calculate company.json              # 均等割と別表の計算（JSON または CSV）。帳票の式・帳票間のチェックも通す
opentax export-etax company.json -o out.xtx # e-Taxソフト（ダウンロード版）に組み込める .xtx を作り、公式XSD で検証する
  #   --balance 科目残高.txt --supplement 足す欄.json   内訳書も入れる
  #   --payroll 給与の記録.json                         役員給与等・人件費の内訳書も入れる
  #   --gaikyo 概況書.json                              法人事業概況説明書も入れる
opentax local-tax company.json -o out.html  # 地方税の一覧（第六号様式・第二十号様式の欄ごとの金額。スマホで見られる HTML）
```

入力の見本（架空の法人）: [tests/cases/open-shoji/input.json](tests/cases/open-shoji/input.json)、
内訳書・概況書・給与の記録つき（東京都の特別区）: [tests/cases/open-shoji-tokyo/](tests/cases/open-shoji-tokyo/)

e-Taxソフトへの組み込み: [docs/etax/IMPORT_GUIDE.md](docs/etax/IMPORT_GUIDE.md)
