# OpenTax Japan

日本の申告書（法人税・地方税・消費税・所得税・相続税・給与と年末調整など）の e-Tax 用データと申告書一式を作るオープンソースです。
特定の税務ソフトに頼らず、国税庁が公開している e-Tax 仕様書（XML構造設計書・帳票フィールド仕様書・XMLスキーマ・帳票間連動仕様書）を一次資料にします。

> **開発中です。** 申告に使う前に、ほかのソフトの結果や国税庁の資料と必ず照らし合わせてください（`opentax compare` で欄ごとに比べられます）。

## 免責

- **計算結果・出力データの正しさは保証しません。**
- **申告の内容と責任は利用者にあります。** 提出前に必ず利用者自身で確認してください。
- このソフトは国税庁・地方税共同機構と関係がありません。

## かんたん入口（ファイルを入れるだけ）

Web 画面（[https://opentax-japan.github.io/opentax-japan/](https://opentax-japan.github.io/opentax-japan/)）のトップに、ファイルやフォルダを落とすだけの入口があります（DESIGN.md §24）。

- **読み取り層**（入力を作るところ）と**計算層**（opentax.api。AI を使わない）を分けています。
  - CSV・TXT（残高試算表・月次推移表・仕訳帳。仕訳帳からは残高試算表と月次推移表を作ります）・前期の申告データ（.xtx。どのソフトで作ったものでも）・JSON は、ブラウザの中のプログラムが読みます。
    会社名・所在地・株主・繰越欠損金などは前期の .xtx から読み取るので、人が打つ欄はほとんどありません。
  - PDF・写真・形のばらばらな表は AI で読みます。読んだ値には「AI」の印と出典（どのファイルのどこ）を付けて画面に出し、人が確かめます。
    - 公開画面: 利用者が自分の Claude API キーを入れ、送る内容（ファイルと指示の全文）を見て同意したときだけ、api.anthropic.com へ送ります。既定はオフで、キーも中身も保存しません。
    - API キーがないとき: 「指示をコピー」で自分の AI のチャット（Claude・ChatGPT など）にファイルと一緒に送り、返ってきた答えを画面に貼ります。画面からは何も送りません。
    - 事務所: Claude Code に PDF を読ませて読み取り結果の JSON（形は docs/intake.md）を作り、画面に落とせば同じ計算が走ります（`opentax intake` でも同じ）。
  - 複数のファイルで値が食い違えば候補を並べて1つ選んでもらい、どうしても読めない欄と申告調整の確認（役員給与・交際費の接待飲食費など）だけを聞きます。
- できた申告書は、印刷（PDF への保存も）・まとめて保存（.zip）・共有（スマホ・PC の共有で LINE・メールなどのアプリへ。送るのは利用者の端末のアプリ）・
  スマホで同じ画面を開く QR（中身は渡しません）で受け取れます。サーバーには何も送りません。
- 入口から、法人（RED・BLACK）・個人（BLUE・WHITE）・事業所税と宿泊税（GREEN）・相続税（GOLD）を作れます。入れたファイルの中身で税目を見分け、「作れる申告書」に色のカードで出します（いくつもあれば押して切り替え）。色ごとの「見本で試す」もあります。PINK（タイムカードから給与明細、年末調整）も入口から作れます。

### フォルダから集めて一気に作る

書類の入ったフォルダ（サブフォルダも）を渡すと、ファイル名ではなく中身で種類を見分け、申告に要るものだけを選んで申告書一式まで作ります（DESIGN.md §24.8）。

```
opentax collect <フォルダ> --task 法人|個人|相続|宿泊税|事業所税 [--period 2026-09-30] [-o 申告書一式.html]
```

同じ種類が複数あれば新しい期を選び、使ったもの・使わなかったもの・足りない書類・人が答える問いを一覧にします。画面の「フォルダを選ぶ」も同じ判定です。

## RED・BLACK（法人）の中身

普通法人・中小法人・青色申告の法人を対象にします。RED は所得金額が0以下の赤字の法人、BLACK は黒字の法人（税額の計算まで）です。

- 法人税: 別表一・別表二（同族会社等の判定）・別表四（簡易様式）・別表五(一)・別表五(二)・別表六(一)（所得税額の控除）・別表七(一)（欠損金）・
  別表八(一)（受取配当等の益金不算入）・別表十四(二)（寄附金の損金算入）・
  別表十五（交際費等）・別表十六(一)(二)（減価償却。耐用年数省令の償却率で計算して固定資産台帳と比べ、当期に取得した資産には使えそうな特例を候補として出します。DESIGN.md §21）
  - 預貯金の利子・配当の源泉所得税の還付、中間納付の還付、前期の未納法人税等・事業税等の納付、損金経理をした延滞税・加算税・罰金等も扱います
  - 申告調整の漏れ止め: 決算書（残高試算表）を渡すと、損益の全科目を申告調整が要るかどうかで点検し、結果を一覧にします。
    寄附金の別表は科目残高（補助科目＝寄附先）から作ります。申告調整の要る科目で作れないもの・入力や確認のないもの
    （貸倒引当金・役員給与の確認など）があれば止めます（DESIGN.md §19）
  - 出力: e-Taxソフト（ダウンロード版）に取り込める `.xtx`。電子署名・送信は e-Taxソフトで行います
- 地方税: 第6号様式（道府県民税・事業税・特別法人事業税）・第6号様式別表九（事業税の欠損金）・第20号様式（市町村民税）・均等割の計算
  - 出力: 計算結果の一覧（欄ごとの金額と PCdesk に入力する順番）。PCdesk への入力・電子署名・送信は利用者が行います
  - 納付書: 申告書一式に、第十二号の二様式（道府県民税・事業税・特別法人事業税）と第二十二号の四様式（市町村民税）を様式の画像の上に金額・納期限を置いて出します（口座番号・課税事務所などは空欄。eL-QR はありません）
  - 対応している自治体: 全都道府県・全市町村（均等割の税率は総務省「法人住民税・法人事業税 税率一覧表」の各年4月1日現在の税率。申告の前に自治体の資料で確かめてください）。岡山県・岡山市・倉敷市・東京都の特別区は条例・自治体の資料で確かめた設定を使います。事務所の市町村は名前か全国地方公共団体コード（offices[].code）で指定します。分割法人は事務所等ごとに期末の従業者の数（offices[].employees）と、事業税の分割基準の事業の区分（company.division_business: 製造業・その他の事業）を書きます（DESIGN.md §29.1）
- 添付書類（.xtx に一緒に入れます）
  - 勘定科目内訳明細書: 預貯金等・売掛金・仮払金/貸付金・買掛金・仮受金/預り金・借入金・役員給与等/人件費・地代家賃・雑益雑損失の9様式。
    会計ソフトの残高試算表（CSV・TXT。ソフトを問いません）と給与の記録から作り、足りない欄（相手先の所在地など）は JSON で足します
  - 法人事業概況説明書: 主要科目は科目残高から、月別の売上・仕入は会計ソフトの月次推移表（CSV・TXT）から、従事員・人件費・役員報酬は給与の記録から、
    そのほかの欄は JSON から作ります（金額は千円未満切捨て。国税庁「法人事業概況説明書の記載要領」による）
- 給与の記録: 計算済みの給与・賞与を記録し、源泉所得税の納付額・賃金台帳・内訳書の元にします（給与の計算は PINK の `opentax kyuyo`）
- 消費税（一般課税・法人）: 申告書（一般用）第一表・第二表・付表1-3・付表2-3 の .xtx（`opentax shohi`）。
  割戻し計算・積上げ計算、全額控除・個別対応方式・一括比例配分方式、特定課税仕入れ。国税庁の「申告書（一般用）の書き方」の2つの設例と数字が一致します
- 消費税（2割特例・法人）: 付表6 と申告書（一般用）の .xtx（入力に `"method": "two_tenths"`。令和8年9月30日を含む課税期間まで）
- 消費税（簡易課税・法人）: 申告書（簡易課税用）第一表・第二表・付表4-3・付表5-3 の .xtx（入力に `"method": "simplified"` と事業区分ごとの売上げ）。
  原則計算・75%以上の特例計算から有利なものを選びます。国税庁の「申告書（簡易課税用）の書き方」の設例と数字が一致します
- 所得税（個人・令和7年分）: 申告書 第一表・第二表、青色申告決算書（一般用・不動産所得用。損益計算書・減価償却費の計算・貸借対照表）、収支内訳書（白色）、医療費控除の明細書の .xtx（`opentax kojin`。手続 RKO0010）。
  事業・不動産（残高試算表から決算書を作ります）・配当・給与・雑（公的年金等など）・一時の所得と、主な所得控除（特定親族特別控除を含む）・配当控除・復興特別所得税。
  国税庁「確定申告の手引き」の申告書の記載例・設例と数字が一致します。
  分離課税（第三表）: 土地・建物等の譲渡（3,000万円の特別控除・軽減税率・特定分）・株式等の譲渡・上場株式等の配当等の申告分離課税・譲渡損失の繰越控除・先物取引。
  国税庁「譲渡所得の申告のしかた」「株式等の譲渡所得等の申告のしかた」の記載例と一致します。損失申告・住宅借入金等特別控除などは対象外で止まります。令和8年分は国税庁の仕様の公表待ちです
- 相続税（令和6年1月1日以後の相続）: 申告書 第1表・第1表（続）・第2表・第4表・第5表・第6表・第7表・第8の8表・第9表・第10表・第11表・
  第11・11の2表の付表1（小規模宅地等）・第13表・第14表・第15表の .xtx（`opentax souzoku`。手続 RKS1000）と申告書一式の HTML。
  法定相続分（民法第900条・第901条）・基礎控除・総額・あん分・2割加算・配偶者の税額軽減・未成年者控除・障害者控除・相次相続控除・
  生命保険金等の非課税・暦年課税の贈与の加算（7年への延長と100万円控除）・代償財産。国税庁「相続税の申告のしかた」の記載例と数字が一致します。
  財産の評価（土地・株式）は評価済みの額を入れます。小規模宅地等の特例と配偶者の税額軽減は、選ぶのは申告する人です（OpenTax は候補と試算を出します）
- 事業所税: 申告書（地方税法施行規則 第四十四号様式）を様式の上に値を置いて HTML で作ります（`opentax jigyosho`）。課税団体75・税率・免税点・課税標準の特例は e-Gov の条文から作った設定。
  岡山市「事業所税の手引」の税額計算例と一致します
- 宿泊税（長野県）: 予約管理サービスの宿泊税明細（日別・予約ごとの CSV）から、納入申告書（様式第２号の上に値）と宿泊税月計表を作ります（`opentax shukuhaku`）。
  市町村宿泊税のある市町村・ほかの自治体はまだです

### 対象外

次のものは扱いません。**入力に含まれていたら「OpenTax RED の対象外です」というエラーで止まります。**

- 黒字法人のうち次のもの（2026-11-14 から、黒字の中小法人の法人税・地方法人税・防衛特別法人税・法人税割・事業税・特別法人事業税を計算します。DESIGN.md §11）:
  法人税割に不均一課税がある市町村のうち札幌市・大阪市以外（2026-11-15 から東京都の特別区の都民税と、札幌市・大阪市の不均一課税を計算します。DESIGN.md §29.7・§29.8）、
  超過課税の軽減の条件・税率を読めない都道府県、所得が年10億円超、
  医療法人、電気供給業・ガス供給業・保険業・貿易保険業、令和元年10月1日より前に開始した事業年度
- 税額控除（所得税額の控除は預貯金の利子などの源泉所得税だけ扱います。配当など所有期間の按分が要るものは対象外）
- 中間申告そのもの（中間申告で納付した額の控除・還付は扱います）
- 外形標準課税（資本金1億円超。資本金1億円以下でも対象になる法人は company.business_tax_pro_forma_standard で止めます）
- 欠損金の繰戻し還付
- グループ通算
- 税額の計算を変える特別措置の適用。適用額明細書は、中小企業者等の法人税率の特例・認定NPO法人等への寄附金と、会計の数字に入っている特別措置（special_measures_reported）について作ります
- 分割法人（事務所・事業所が2つ以上の都道府県または市町村にある法人）のうち次のもの（2026-11-15 から分割法人の法人税割・事業税・特別法人事業税・均等割と、
  第十号様式・第二十二号の二様式の数字を地方税の一覧に出します。DESIGN.md §29）: 電気供給業・ガス供給業・倉庫業・鉄道事業・軌道事業、
  同じ事業年度に新設して廃止した事務所等、都内の主たる事務所等が事業年度の中途で特別区の間を移った法人の均等割。分割法人の紙の様式・納付書は作りません
  （東京都の2つ以上の特別区・特別区と都内の市町村の両方に事務所等がある法人は 2026-11-15 から計算します。都外に本店がある法人は offices[].tokyo_main で都内の主たる事務所等を選べます）
- 添付書類のうち財務諸表（貸借対照表・損益計算書など）。e-Taxソフトなどで別に添付してください
- eLTAX 用の取込ファイル（地方税共同機構への仕様の開示申込みの回答を待っています）

今後対応予定:
- Excel（.xlsx）を直接読むこと（今は CSV・TXT で書き出したものを読みます。会計ソフトは問いません）
- 前期の別表十六（減価償却）・別表五(二) を行ごとに読んで初期値にすること
- 赤字の法人でまだ扱えないもの: 前期の未収還付税金、仮払経理による中間納付、別表十六の6列目以降（2枚目）

- 地方税（eLTAX）の取込ファイル、分割法人の紙の様式（第十号様式など）・納付書
- 消費税の旧税率の取引・課税貨物・調整対象固定資産の調整
- 所得税の損失申告（第四表。損益通算しても経常所得が赤字になるもの）・居住用財産の譲渡損失の特例・買換え交換・先物取引の繰越損失の付表・損失と公的年金等がある申告・住宅借入金等特別控除・令和8年分

  相続時精算課税（第11の2表）・暦年課税分の贈与税額控除（第4表の2）・還付（第1表の付表2）がある申告は、計算と一式の表は作れますが .xtx は作りません

## 国税庁の仕様書について

仕様書は国税庁の著作物のため、このリポジトリには含めていません。
取得スクリプトが国税庁のサイトからダウンロードし、`.cache/` に置きます。取得したファイルは SHA256 で照合します。

## Web 画面

[https://opentax-japan.github.io/opentax-japan/](https://opentax-japan.github.io/opentax-japan/)（独自ドメイン opentax.jp に移る予定）

- ブラウザだけで使えます（Windows ソフトのインストールは不要）
- 計算はブラウザの中で行い、入力した内容はサーバーに送りません。localStorage などにも残しません。保存は「入力をファイルに保存」でダウンロードしたファイルだけです
- e-Tax 用の .xtx を作るときは、国税庁から取った e-tax19.CAB を画面で選びます（その CAB で検証してから書き出します）
- 申告書一式（report.html）: デモの会社（架空）の決算書を入れると、法人税の別表 → 消費税 → 概況書 → 決算書 → 内訳書 → 地方税 を順に作り、1枚の見やすい HTML に並べます（印刷・保存できます）
- 内訳書・概況書: 計算結果の下で、科目残高一覧表・推移表・内訳書の補足・給与の記録・概況書の入力（JSON）を選ぶと、.xtx に一緒に入れます
- 給与の記録の画面（payroll.html）もあります

## 使い方

作成済み:
```
opentax fetch-spec --set ksk2-2026-08       # 仕様書の取得と SHA256 照合（--check で国税庁の改訂を検知）
opentax build-layout --set ksk2-2026-08     # XSD から帳票ごとの layout を作る
opentax build-catalog --set ksk2-2026-08    # 帳票フィールド仕様書から field_catalog を作る
opentax build-checks --set ksk2-2026-08     # 帳票の一致チェックを仕様書から作る
opentax calculate company.json              # 均等割と別表の計算（JSON または CSV）。帳票の式・帳票間のチェックも通す
opentax export-etax company.json -o out.xtx # e-Taxソフト（ダウンロード版）に組み込める .xtx を作り、公式XSD で検証する
  #   --balance 残高試算表.csv --supplement 足す欄.json 内訳書も入れる
  #   --payroll 給与の記録.json                         役員給与等・人件費の内訳書も入れる
  #   --gaikyo 概況書.json                              法人事業概況説明書も入れる
  #   --trend 月次推移表.csv                            概況書の月別の売上・仕入を推移表から作る
opentax local-tax company.json -o out.html  # 地方税の一覧（第六号様式・第二十号様式の欄ごとの金額。スマホで見られる HTML）
opentax shohi shohi.json -o shohi.xtx       # 消費税（法人）の .xtx（見本: 一般 tests/cases/kokuzei-shoji-shohi/input.json・簡易 tests/cases/kasumi-shokai-kani/input.json）
opentax kojin tests/cases/kokuzei-taro-kojin/input.json --business tests/cases/kokuzei-taro-kojin/business_balance.csv --real-estate tests/cases/kokuzei-taro-kojin/real_estate_balance.csv -o kojin.xtx --report 個人.html   # 所得税（個人）
opentax souzoku tests/cases/kokuzei-taro-souzoku/input.json --report 相続.html   # 相続税（-o で .xtx。送る人の user_id が要る）
opentax report --demo -o 一式.html         # 申告書一式（HTML 1枚）。自社の分は input.json --balance --trend --payroll --supplement --gaikyo --shohi
opentax compare 他のソフトの申告データ.xtx input.json --csv 照合.csv   # 並行照合: 他のソフトの申告書と欄ごとに比べる（docs/compare.md）
opentax collect <フォルダ> --task 法人 -o 一式.html   # フォルダから書類を見分けて一式まで
opentax intake <ファイル…> -o 下書き.json   # 読み取り層: ファイルから入力 JSON の下書き
opentax kyuyo tests/cases/kyuyo-sample/kyuyo_input.json --report 給与明細.html   # 給与計算（PINK）
opentax nencho tests/cases/nencho-r08/input.json -o nencho.xtx --report 年調.html   # 年末調整・源泉徴収票・法定調書合計表（PINK）
opentax jigyosho tests/cases/jigyosho-sample/input.json --report 事業所税.html   # 事業所税（GREEN）
opentax shukuhaku tests/cases/shukuhaku-nagano/meisai_2026-06.csv --facility tests/cases/shukuhaku-nagano/shisetsu.json --month 2026-06 --report 宿泊税.html   # 宿泊税・長野県（GREEN）
```

入力の見本（架空の法人）: [tests/cases/open-shoji/input.json](tests/cases/open-shoji/input.json)、
内訳書・概況書・給与の記録つき（東京都の特別区）: [tests/cases/open-shoji-tokyo/](tests/cases/open-shoji-tokyo/)

e-Taxソフトへの組み込み: [docs/etax/IMPORT_GUIDE.md](docs/etax/IMPORT_GUIDE.md)
（法人税の別表・内訳書は e-Taxソフトへの組み込みを確かめました。概況書と消費税の .xtx、2026-10-04 に足した内訳書7様式（受取手形・棚卸資産・有価証券・固定資産・支払手形・土地の売上高等・事業所別）は、まだ組み込みを確かめていません）
