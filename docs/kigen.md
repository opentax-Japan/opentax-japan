# OpenTax PLATINUM: 期限一覧と進捗（opentax kigen）

税理士事務所が、関与先ごとに「その月に期限が来る申告・納付」を一覧にし、進捗を書き込むための道具です。
期限は条文から数え、行ごとに根拠の条文を出します（DESIGN §28）。

## 使い方

```
opentax kigen 関与先一覧.csv --month 2026-11 --progress 進捗.json --html 一覧.html --csv 一覧.csv
opentax kigen 関与先一覧.csv --progress 進捗.json --set "101|源泉|2026-07〜12分" 納付済 --memo "1/15 ダイレクト納付"
```

Web 画面は `platinum.html`（関与先の一覧と進捗のファイルを開く → 状態を選ぶ → 進捗をファイルに保存）。

- 状態: 未着手・資料待ち・作成中・確認待ち・送信済・納付済・完了・対象外
- 「済」に数えるもの: 完了・対象外。納付だけの行（源泉・住民税・予定納税）は納付済も。納付のない提出物（法定調書・給与支払報告書・償却資産）は送信済も。
- 行の ID は `コード|種類|期間`。進捗のファイルは `{"kind": "opentax-progress", "items": {ID: {status, memo, updated}}}`。

## 関与先の一覧（CSV・JSON）

1行が1社（1人）。見出しの名前で読みます（列の順は自由。UTF-8・Shift_JIS どちらでも）。見本: `tests/cases/platinum-kigen/clients.csv`（架空）。

| 列 | 書き方 | 省略したとき |
|---|---|---|
| コード・名前 | 必須 | — |
| 区分 | 法人／個人 | 法人 |
| 決算月 | 1〜12（法人は必須） | 個人は12 |
| 担当 | 自由 | 空 |
| 延長 | 法人税の申告期限の延長の月数（法人税法第75条の2） | 0 |
| 消費税 | 課税／免税 | 免税（出さない） |
| 消費税の延長 | あり／なし（消費税法第45条の2。法人税の延長がある法人だけ） | なし |
| 消費税の中間 | なし／1／3／11、または「前期 金額」（直前の課税期間の確定消費税額（国税）。消費税法第42条で回数を決める） | なし |
| 法人税の中間 | あり／なし、または「前期 金額」（前期の確定法人税額。前期12か月として ×6/12 が10万円を超えれば出す） | なし |
| 予定納税 | 個人。あり／なし（所得税法第104条） | なし |
| 源泉 | 毎月／特例／なし（所得税法第183条・第216条）。毎月・特例なら翌年1月31日の法定調書・給与支払報告書も出す | なし |
| 住民税 | 特別徴収。毎月／特例／なし（地方税法第321条の5・第321条の5の2） | なし |
| 償却資産 | あり／なし（地方税法第383条） | なし |
| 設立 | 法人の最初の事業年度の初日 YYYY-MM-DD（最初の事業年度は中間申告を出さない） | 空 |
| 月次 | 試算表を作る間隔: 毎月／隔月／四半期／半期／決算のみ／なし（区切りは決算月にそろえる） | なし |
| 試算表の期限 | 事務所の目安: 翌月末／翌月20日／翌々月末 など（法定の期限ではないので休日でずらさない） | 翌月末 |

## 試算表の進捗表

`--grid 進捗表.html`（Web 画面では一覧の下）で、月次のある関与先 × 12か月の表を作ります。マスは進捗の状態
（行の ID は `コード|試算表|YYYY-MM分`）。報告済・完了で「済」、目安の期限を過ぎて済でない月は赤。Web 画面ではマスを押すと
未着手→資料待ち→作成中→確認待ち→報告済 と進みます。

## 扱わないもの

- 災害等による期限の延長（国税通則法第11条）、個別の指定・承認の中身（届出が出ているかは一覧に書いたとおりに扱う）
- 課税期間の短縮の特例、仮決算による中間申告の選択、通算法人
- 個人の消費税の毎月の中間申告（止めます）
- 祝日の表（内閣府）にない年の期限（止めます。表を新しくしてください）
