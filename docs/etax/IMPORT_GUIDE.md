# e-Taxソフト（ダウンロード版）への組み込み手順と確認項目

OpenTax RED が作った .xtx を e-Taxソフト（ダウンロード版）に組み込み、内容を確かめる手順。
**この手順では送信しない。** 確かめ終わったら、組み込んだデータは削除する。

## 1. 準備

1. 仕様書を取得する
   ```
   opentax fetch-spec --set ksk2-2026-08
   ```
2. 入力ファイルを作る
   - 最初は架空の法人の見本 `tests/cases/open-shoji/input.json` をコピーして使う
   - 置き場所は `private/`（リポジトリに入らない）。実在の会社のデータは必ずここに置く
   - `company.user_id` は、組み込みに使う e-Taxソフトの利用者ファイルと同じ利用者識別番号（16桁）にする
     （違う番号だと「e-Taxソフトに必要な税目（年分含む）がインストールされていない可能性があります」と出て組み込めない。
     2026-10-01 に e-Taxソフトで確認）
   - 利用者ファイルは、その法人の利用者識別番号で作る。法人税を追加インストールしていても、
     新規作成の「税目」に法人税が出ない利用者ファイルでは組み込めない（2026-10-01 に確認）
3. .xtx を作る（公式XSD で検証してから書き出す。検証で誤りがあれば書き出さない）
   ```
   opentax export-etax private/input.json -o private/open-shoji.xtx
   ```
   - 別表二の割合の端数処理（切り捨て／四捨五入）が決まるまでは、ここで止まる

## 2. e-Taxソフトに組み込む

1. e-Taxソフト（ダウンロード版）を起動し、利用者ファイルを開く
2. メニューの「作成」→「申告・申請等」をクリックする
3. 「申告・申請等一覧」画面で「組み込み」をクリックし、作った .xtx を選ぶ
   - 出典: e-Tax よくある質問「受信通知からダウンロードしたデータ(拡張子は.xtx)をe-Taxソフトで表示・印刷するにはどうすればよいですか。」 https://www.e-tax.nta.go.jp/toiawase/qa/yokuaru05/10.htm
4. 組み込んだ申告を開き、帳票を表示する

## 3. 確かめること

| # | 確かめること | 背景 |
|---|---|---|
| 1 | 組み込みでエラーが出ないか。出たら、メッセージの全文 | 確認済み（2026-10-01、e-Taxソフト DL版・法人税 令和8年4月1日以後終了事業年度分。架空の法人で7帳票とも「組み込み」）。管理部（CATALOG）の RDF は、e-Taxソフトが切り出したファイルと同じ書き方にしている |
| 2 | 帳票が7つ表示されるか（別表一・一次葉一・二・四（簡易様式）・五(一)・五(二)・七(一)） | 確認済み（2026-10-01。版は 7.0・1.0・5.0・25.0・16.1・10.0・13.0）。別表一 次葉一（HOA114）は手続XSD で必須 |
| 3 | 下の表の金額が、そのとおりに表示されるか | 別表四（23・26・34・39・43 が ▲）と別表七(一)（控除未済・当期分・翌期繰越の合計）は確認済み（2026-10-01、東京の見本 tests/cases/open-shoji-tokyo で。金額は見本の岡山版と 1,000 円違う） |
| 4 | 金額が 0 の欄が空欄になっていても問題ないか（エラー・警告が出ないか） | 0 の金額は出していない |
| 5 | 別表七(一) の1行目「控除前所得金額」の表示 | 赤字のときの書き方が仕様書から分からないため、今は出していない。TPS1000 の赤字法人の別表七(一)と見比べる |
| 6 | 別表二の割合（小数1桁・3桁）の表示 | 端数処理を TPS1000 で確かめてから決める |
| 7 | 別表一の「添付書類」「同非区分」「法人区分」「申告の種類」の表示 | 添付書類は既定で「添付あり」（財務諸表・内訳書・概況書は e-Taxソフトで別に添付する前提） |
| 8 | 別表一の「提出年月日」「決算確定の日」 | 入力にある日付だけ出している |
| 9 | IT部（納税地・法人名・税務署・事業年度）の表示 | IT部の版 1.5 は e-Taxソフトが切り出したファイルと同じ（2026-10-01 に確認）。一覧に法人名・提出先税務署が出ることは確認済み |

## 4. 終わったら

- 組み込んだ申告データを e-Taxソフトから削除する（送信しない）
- 確かめた結果（エラーの全文、表示が違った欄）を知らせる。画面の写しを送るときは、架空の法人のデータで撮る
