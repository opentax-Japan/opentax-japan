会計ソフトから出したファイルを入れるだけで、申告書を作ります。計算はこの画面の中だけで行い、ファイルはどこにも送りません。

ここにファイルを入れる

フォルダごとでもかまいません（パソコンは引きずって落とせます）

何を入れればいい？
  • 法人（RED・BLACK） … 残高試算表（CSV・TXT）と前期の申告データ（.xtx）。あれば月次推移表・給与の記録も
  • 個人（BLUE・WHITE） … 事業・不動産の残高試算表（CSV）、前年の申告データ（.xtx）、源泉徴収票・控除証明書・特定口座年間取引報告書
  • 事業所税・宿泊税（GREEN） … 事業所税の入力（JSON）、予約管理サービスの宿泊税明細（CSV）
  • 相続税（GOLD） … 被相続人・相続人・財産・債務の入力（JSON。土地・株式は評価済みの額）
  • 源泉徴収票・証明書・決算書の PDF や写真は、この画面のプログラムでは読めません。下の「AI で読む」を使うか、事務所の Claude Code で読んだ値（JSON）を入れてください
  • Excel は「名前を付けて保存」→「CSV UTF-8」で保存し直してから入れてください
  • フォルダごと入れると、中身で見分けて申告に要るものだけを選びます（同じ種類が複数あれば新しい期）
  • 色ごとの必要書類は、下の「必要書類」に一覧があります。入れたファイルが読めると自動でチェックが付きます

作れる申告書

入れたファイルの中身から、どの申告書を作るか決めました。違う申告を作るときは押して切り替えてください。

読んだファイル

    AI で読む（PDF・写真）

    この画面のプログラムで読めなかった PDF・写真を、あなたの Claude API キーで AI に読ませます。入れたファイルが Anthropic 社（api.anthropic.com）へ送られます。 キーと中身はこの画面にだけ置き、保存しません。使わなければ何も送りません。
